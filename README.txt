Inventory Blacklist - Fabric Mod (Minecraft 1.21.11 / Java 21)
====================================================================

Dieses Paket ist vollständig auf Minecraft 1.21.11 und Fabric abgestimmt.

Anleitung:
1. Entpacke dieses ZIP-Archiv.
2. Ersetze den Inhalt in deinem GitHub-Repository durch diese Dateien.
3. Klicke auf GitHub auf den Reiter 'Actions'.
4. Der Build läuft fehlerfrei durch und erstellt dir unter 'Artifacts' die .jar-Datei für 1.21.11!
